# 课业智析

课业智析是一套面向学校课程的本地教学辅助平台。它帮助教师把课程资料、题库、学生测评、错题订正和班级学习画像放在同一个系统中，并通过有来源依据的智能分析辅助教学。

平台包含管理员、教师和学生三类账户，所有课程、班级、作答和画像数据都按账户权限隔离。

## 能做什么

### 管理员

- 创建教师和学生账号；
- 注销不再使用的账号；
- 查看基本账户状态，但不参与课程教学。

### 教师

- 创建课程和班级，维护学生名单；
- 上传课程资料和题库，由后台 Worker 自动解析；
- 配置班级独立的 DeepSeek 服务；
- 发布诊断测评、练习、阶段评测和错题订正；
- 查看班级画像、学生画像、错题分布和教学建议；
- 复核低置信度机器评分并进行改判。

### 学生

- 进入本人所在的课程和班级；
- 完成测评、练习和错题订正；
- 查看个人学习画像与逐题反馈；
- 针对课程内容发起带有资料依据的答疑。

## 功能模块

| 模块 | 面向用户的作用 |
|---|---|
| 平台与权限 | 登录、账号、课程、班级和访问控制 |
| 课程资料 | 接收并解析教师上传的课程文件 |
| 内容检索 | 从课程资料中找到与问题相关的原文依据 |
| 知识与题库 | 组织知识点、题目、评分规则和试卷结构 |
| 学习任务 | 识别并组织答疑、测评、练习和订正任务 |
| 学习画像 | 维护学生掌握度、薄弱点和班级统计 |
| 辅导流程 | 决定提示、追问、补学或结束等下一步动作 |
| 智能能力 | 调用 DeepSeek 完成知识解析、语义评分和反馈 |
| 测评评分 | 生成试卷、保存作答并完成客观与主观评分 |
| 教师分析 | 提供班级分析、学生分析、复核和教学建议 |

## 快速启动

Windows 可执行版无需安装 Python：

1. 解压“课业智析-可执行版”；
2. 双击 `启动课业智析.cmd`；
3. 首次启动时按提示设置管理员账号和密码；
4. 浏览器会自动打开登录页面。

平台由 Web 服务、知识解析 Worker 和事件 Worker 三个进程组成，启动脚本会同时启动它们。结束使用时双击 `停止课业智析.cmd`。

完整操作方法见[使用说明](使用说明.md)。

## 数据位置与安全提示

- 数据库、上传文件、日志和本地密钥保存在程序目录的 `runtime` 中；
- 本地启动密钥保存在程序目录的 `.env` 中；
- 不要把 `runtime`、`.env` 或真实 DeepSeek 密钥发送给他人；
- 备份时应先停止平台，再整体复制 `runtime`；
- 本地可执行版用于单机或可信局域网环境，不应直接暴露到公网。

## 技术信息

课业智析采用 Python 3.12、Django 5.2、Pydantic 2 和 SQLite。源码版也支持配置 PostgreSQL 与 pgvector，用于需要集中部署和更高并发的环境。
