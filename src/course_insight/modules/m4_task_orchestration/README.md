# M4 任务与测评编排

## 负责人

陈

## 职责

识别任务类型，用稳定幂等键冻结课程、知识包、蓝图、工作流、下一模块
与策略版本。M4 只编排 M0—M9 现有模块，不为 Django、RAG、DeepSeek 或
学习模型新建责任域。

## 输入来源

- 学生任务文本与可选任务类型提示。
- M3 `KnowledgeBundle` 及其蓝图/版本。
- 可选 M5 `LearnerStateSnapshot`；后续可在同一契约边界消费经审核的诊断结果。

## 输出

`TaskPlan`，供 M8 出卷/评分编排和 M6 辅导控制。任务身份不依赖自由文本措辞，
相同业务输入必须重用同一版本化计划。

## 禁止事项

不得把措辞细微差异纳入幂等身份、随机选路、绕过蓝图或版本、直接调用
模块仓储，或把外部适配器类型写入 `TaskPlan`。
